# HellCat-Bullet-Hell-Game-
This is a 2D arcade-style action game built in Unity. The player controls a character that can move around the screen, shoot projectiles, and avoid enemies. The goal is to survive while defeating incoming enemies using quick reflexes and strategy.

Key Features:

Player Controls: Smooth movement and shooting mechanics.

Enemy Spawning: Enemies appear on screen and actively move toward the player.

Projectiles & Cleanup: Player bullets interact with enemies and are automatically cleaned up to optimize performance.

Boundaries: Player movement is restricted within the game screen so they cannot move off-screen.

Game Management: A GameManager script tracks progression, win/lose conditions, and scene transitions.

Main Menu & UI: Includes a functional main menu with start, settings, and quit options.

Scenes: Main Menu, Gameplay, and any additional scenes included for testing or progression.

The game is designed as a complete Unity project showcasing player input, game logic, UI integration, and scene management while building a fun and simple gameplay loop.
